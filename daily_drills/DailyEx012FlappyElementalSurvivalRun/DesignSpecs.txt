Flappy Elemental - Survival Run

Premise:
You're flying through the gauntlet. Obstacles appear one by one. Each has a random element. You have a current element, but you can swap it by grabbing a chip
before engaging. Survive as long as possible.

Setup:
- Player starts with a random element
- Each round: A new obstacle appears with a random element
- Before, player can grab a random element chip (y/n)
- Player then chooses to engage or dodge
- Engaging resolved by element rules
- Dodging always succeeds but costs 1 HP
- Plyer starts with 5 HP

Rules:
- Use your 'Element' enum and GetWinner() from memory
- Use Console.ReadLine() for player input
- Use int.TryParse() -> Present numbered choices, validate input
- Grabbing a chip: Reassings player element randomly using GetRandomElement()
- Engaging: 
    - Win -> Obstacle destroyed, continue. 
    - Draw -> Lose element (become None).
    - Lose -> Game over
    - Skip -> Lose 1 HP
- If player element is 'None' and they engage, they lose
- Game ends when HP hits 0 or Obstacle wins round. Print score (rounds survived)
- Use a ternary at least once
- Use modulus to trigger an "element shift" warning message every 3rd round

Todos:
- Make sure each fight accounts for a Draw outcome -- DONE
- Make sure to ask to swap element before next encounter -- DONE
- Setup counting rounds survived -- DONE
